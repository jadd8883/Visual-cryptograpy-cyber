# Visual-cryptograpy-cyber
A Python Flask application for image-based visual cryptography and secret sharing.
2-out-of-2 visual cryptography scheme.

## Features
- Upload a secret image
- Generate two visual cryptography shares
- Download the generated shares
- Reconstruct an image from two shares

## Technologies
- Python
- Flask
- Pillow
- NumPy
- HTML and CSS

## Installation

Install Python 3, then run:

```bash
python -m pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000 in your browser.
